# Architecture & Design Decisions — ev-charging-stations-api

Log of decisions made for this project, recorded before implementation where possible and after the
fact where a decision was forced by an audit finding.

## 2026-10-15: Initial architecture & scaffolding

- **Domain:** Indian public EV charging station directory and connector lookup.
- **Storage:** In-memory JSON dataset with a spatial pre-index, avoiding native modules on Vercel's
  serverless runtime.
- **Framework:** Node.js + Express, standard envelopes under `/v1`, CORS open, keyless access.
- **Specs:** `DOCS/specs/2026-10-15-ev-charging-stations-design.md` and
  `DOCS/plans/2026-10-15-ev-charging-stations-plan.md`.

## 2026-10-15: Production audit and hardening

Full findings and the commands that reproduced them are in `DOCS/AUDIT-2026-10-15.md`.

### Dataset provenance was false — corrected

The dataset was generated by `Math.random()` but described throughout the project as official
Ministry of Power / BEE data under GODL-India. **Decision:** keep the generated dataset, but label it
honestly everywhere and make that label testable.

- `meta.json` now carries `dataset_status: "generated-sample"` and `provenance.is_official: false`,
  plus the intended source for a future ingest.
- `/v1/meta`, `/health`, `/`, the footer, the status page and the API reference all surface it.
- A backend test asserts the disclosure, so it cannot silently regress.
- The generator is now seeded (mulberry32) so output is byte-identical across runs, and it covers all
  36 states and union territories instead of 22.
- Ingesting the official source is recorded as the next substantive step in `README.md` and
  `STATUS.md`.

### Rate limiting was global — fixed with `trust proxy`

Without `trust proxy`, Express reported the Vercel edge address as `req.ip`, so every caller shared
one 100-request bucket and the API rate-limited globally. Now `app.set("trust proxy", 1)` (overridable
via `TRUST_PROXY_HOPS`), limits are raised to 300/15 min and configurable via `RATE_LIMIT_MAX` /
`RATE_LIMIT_WINDOW_MS`, and a test asserts two forwarded client addresses get independent budgets.

### Validation: reject, never silently ignore

Previously `min_power_kw=abc` skipped the filter while `meta.filters_applied` still reported it, param
values were never trimmed, `radius=0` silently became 10 km, and `/v1/stations/1.5` returned station 1.
**Decision:** every supplied parameter is validated; invalid input is a 400 with a stable code and a
`details` block naming the parameter and the accepted range. Parameters are trimmed, connector
spellings and city aliases are normalised, and ids must be positive integers.

### Filtering moved server-side

The playground filtered the already-truncated nearest-25 page in the browser, which produced false
"no stations found" results. **Decision:** `/v1/stations/near` accepts `connector`, `min_power_kw` and
`operator`, and filters before sorting, so `meta.total_found` is meaningful.

### CORS headers deduplicated in `vercel.json`

`vercel.json` set `Access-Control-Allow-Origin` on `/v1/(.*)` while the Express `cors()` middleware
already did. Vercel appends configured headers to function responses, so production would have emitted
two `Access-Control-Allow-Origin` headers, which browsers reject — a failure invisible in local
development. **Decision:** configure no CORS headers in `vercel.json`; the application owns them.

### Basemap replaced: OpenFreeMap, not CARTO or OSM

- CARTO raster basemaps require an API key since 25 Sep 2026 and watermark keyless requests, so the
  URL recorded in the earlier map plan is dead.
- `tile.openstreetmap.org` forbids application-scale use in its tile-usage policy and offers no SLA.
- **Decision:** MapLibre GL with OpenFreeMap vector tiles — keyless, no registration, no request
  limits, commercial use permitted, MIT-licensed, data © OpenStreetMap contributors. The previous
  dark mode was a `filter: invert(100%) hue-rotate(180deg)` hack over light imagery; it is gone, and
  the map now uses a real light style matching the design system.

### Design system replaced

The dark navy canvas with four competing accents (blue/emerald/amber/teal), shouting uppercase
monospace labels over prose, and glow-on-panel chrome was replaced with a light minimalist system:
near-white surfaces, zinc hairlines, near-black text, a single deep-teal accent, sentence-case type,
and monospace reserved for code, coordinates and identifiers. Colour lives in one place
(`tailwind.config.js` plus CSS custom properties) instead of inline hex in three files.

### Fabricated telemetry removed

The home and status pages published "AVG_SPATIAL_LATENCY < 3.8 ms" and an SLO table as verified
measurements. They were not measurements. **Decision:** the status page now runs a real client-side
probe and reports measured round-trip and server times, or says nothing.

### SEO

- Per-page titles and descriptions moved into `src/content/pageMeta.js`, imported by both the
  prerenderer and the SPA, so static HTML and client-side navigation cannot drift.
- Added `og:image` / `twitter:image` (generated `og-image.png`), `og:site_name`, `og:locale`,
  a favicon link (previously 404 on every page) and an `apple-touch-icon`.
- WebAPI structured data applies to the API landing page only; guide pages carry `TechArticle`.
- `sitemap.xml` `lastmod` is generated from the build date rather than hardcoded.
- Guide titles were 74 characters; they now have short `seoTitle` values under 60.

### No origin, no crawler directives

The project advertised `ev-charging-stations-api.vercel.app` in canonical tags, `og:url`, all eight
sitemap entries, `robots.txt`, the README badges and every code sample — while that host returned 404
on every path. **Decision:** `SITE_URL` (or Vercel's `VERCEL_PROJECT_PRODUCTION_URL`) is the single
source for the canonical origin. When it is unset, the build omits canonical tags, `og:image`,
`sitemap.xml` and `robots.txt` entirely and prints a warning, so nothing ever points a crawler at a
host that is not serving the site.

### Documentation drift corrected

In-app docs and the README advertised `min_power`, `offset`, `meta.query_time_ms`, `meta.returned`,
`meta.lat`, `meta.lng` and a `pincode` field — none of which exist. Code samples pointed at the dead
host and guide snippets hardcoded it. All examples now run against a `BASE_URL` you supply, and the
documented parameters, response shapes and error codes match the implementation.
